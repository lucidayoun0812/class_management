## 🌟 1. 프로젝트 목적 및 핵심 컨셉

1. **쑥쑥 캐릭터 성장 (단일 성장 시스템)**
   - 복잡한 경험치(EXP) 계산 대신, **누적 칭찬 도장 개수**에 따라 내 캐릭터가 직관적으로 진화합니다.
   - 상점에서 보물 쿠폰을 구입해 코인을 소비하더라도, **나무의 성장 단계는 줄어들지 않습니다.**
   - 4단계 성장 과정:
     - **1단계: 꼬마 새싹 🌱** (0~9개)
     - **2단계: 작은 묘목 🌿** (10~29개)
     - **3단계: 큰 나무 🌳** (30~59개)
     - **4단계: 열매 맺은 황금 나무 🍎✨** (60개 이상)

2. **단순하고 안전한 스티커 경제**
   - 2학년 수학 교육과정(두 자릿수 덧셈과 뺄셈)에 맞추어 **도장/코인을 100개 미만(최대 99개)** 으로 엄격히 제한 관리합니다.
   - 쿠폰 교환 시 **칠판 계산기**를 통해 "내 코인 - 쿠폰 가격 = 남는 코인"의 수 연산을 시각적으로 학습합니다.

3. **2학년 맞춤형 1인 1역**
   - 긴 텍스트 대신 **큰 아이콘(그림)** 과 쉬운 이름, 친절한 행동 요령을 제공합니다.
   - 학생 대시보드 중앙에 큰 카드로 강조되어 오늘 할 일을 한눈에 파악합니다.

4. **학급 보상 상점 (특권 쿠폰 중심)**
   - 실물 상품 대신 학급 생활 속 재미를 주는 특권 쿠폰 위주로 구성 ("원하는 자리 앉기", "급식 1등으로 받기", "선생님과 하이파이브", "쉬는 시간 오늘의 DJ" 등).
   - 학생 신청 ➔ 선생님 실시간 승인/반려 ➔ 코인 차감 및 쿠폰함 지급의 체계적인 흐름.

## 🚀 2. 실행 방법 (별도 설치 불필요!)

이 웹 애플리케이션은 **외부 서버나 Node.js 설치가 전혀 필요 없는 순수 브라우저 독립형(Standalone) 웹 앱**입니다.

1. `index.html` 파일을 더블 클릭하거나,
2. 웹 브라우저(Chrome, Edge, Whale, Safari 등)로 `index.html` 파일을 드래그 앤 드롭하면 즉시 실행됩니다.
3. 교실 내 **전자칠판**, **교사용 태블릿(iPad, Galaxy Tab)**, **컴퓨터** 어디서나 완벽하게 동작합니다.

## 📱 3. 화면별 주요 기능 안내

### ① 학생 로그인 및 명렬표 화면 (번호 + 이름 입력 접속)
- 학생이 본인의 **출석 번호**와 **이름**을 입력하여 접속하는 전용 로그인 화면을 제공합니다.
- 우리 반 20명 명렬표(1~10번, 41~50번) 데이터와 대조하여 일치할 때 안전하게 개인 대시보드로 이동합니다.
- 초등 2학년 학생들의 편의를 위해 **[우리 반 명렬표(출석부) 확인하기]** 팝업을 지원하여, 번호를 잊어버린 경우에도 자기 이름을 콕 터치해 원클릭으로 간편하게 입력할 수 있습니다.
- 모든 학생의 초기 도장, 코인 스코어는 **0개**로 시작합니다.

### ② 학생 메인 화면 (성장 일기 대시보드)
- **성장 캐릭터 캔버스**: 4단계로 살아 숨쉬는 생생한 인터랙티브 SVG 캐릭터 (흔들리는 줄기, 무당벌레 친구, 파랑새, 황금 사과).
- **성장 게이지 바**: 다음 단계까지 남은 도장 수를 직관적인 그래프로 안내.
- **지금 쓸 수 있는 코인 잔액**: 큰 글씨와 동전 그래픽으로 표시.
- **오늘 나의 1인 1역 카드**: 큼직한 아이콘과 친절한 행동 요령 제시.
- **내가 가진 보물 쿠폰함**: 선생님 승인 대기 중인 쿠폰과 사용 가능한 쿠폰 티켓 확인 및 "사용하기" 기능.

### ③ 우리 반 보물 상점
- 현재 잔여 코인으로 교환 가능한 쿠폰은 **황금빛 테두리 & ✨ 지금 교환 가능!** 강조 뱃지 부여.
- 쿠폰을 누르면 **칠판 뺄셈 계산기 모달**이 열려 남는 코인을 스스로 확인 후 신청.

### ④ 선생님 관리자 대시보드 (우측 상단 '선생님 모드' 탭)
- **📋 학생 현황 & 도장 지급**:
  - 20명 학생의 출석번호순 카드 목록 및 검색 기능.
  - 학생 카드마다 **[+1 도장]**, **[+5 도장]**, **[-1 차감]** 원클릭 조정 버튼.
  - 레벨업 기준 달성 시 축하 팡파르 음악과 풀스크린 폭죽 파티클 발동!
  - **"전체 학생에게 +1 도장 선물"** 일괄 보너스 버튼.
- **🧹 1인 1역 관리**:
  - 학생별 역할을 드롭다운으로 간편하게 변경.
  - 우리 반 역할 사전 목록 및 새 역할 추가 모달 제공.
- **🔔 쿠폰 교환 신청 승인함**:
  - 학생이 상점에서 신청한 내역을 실시간으로 확인.
  - **[승인하기]** 클릭 시 학생 코인이 자동 차감되며 학생 쿠폰함으로 발급.
- **🏷️ 보물 상점 쿠폰 메뉴판 관리**:
  - 새 쿠폰 등록(이름, 가격, 아이콘, 설명) 및 기존 쿠폰 삭제.
- **🔄 데이터 초기화**: 언제든지 최초 체험용 20명 샘플 데이터로 복구 가능.

## 🎨 5. 특장점 및 디테일

- **Web Audio API 내장 효과음**: 외부 mp3 파일 없이 브라우저 자체 오디오 신시사이저를 이용해 즉각적인 반응성(도장 찍을 때 딩동댕, 코인 짤랑, 레벨업 팡파르, 헤더의 🔊 음소거 토글 지원).
- **폭죽 파티클 애니메이션**: 도장 지급 및 레벨업 시 캔버스 폭죽 효과가 연출되어 아이들의 성취감을 극대화.
- **데이터 자동 저장 (LocalStorage)**: 브라우저를 닫아도 학생들의 도장, 코인, 배정된 역할, 보유 쿠폰이 안전하게 유지됩니다.
